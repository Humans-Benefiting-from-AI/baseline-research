| SIX PATTERNS WORTH NOTICING |
| 1. The AI category is the most crowded and the least differentiated. Roughly a dozen of the 21 are the same product: a chat box with retrieval over Sefaria. The three that stand out (PshatGPT, TzadekAI, Torah Scholar MCP) each broke the chat frame rather than improving inside it. |
| 2. Almost everything is read-only over Sefaria's data. Only a handful produce new structured data (Torah Tree, Pninim, The People's Talmud, Zohar-stories). That is where the scarce asset is: text is free, inference is commodity, structured conceptual metadata is not. |
| 3. Delivery is oversolved, retention is barely touched. Dozens of ways to receive today's daf; one auto-generated quiz, one broken study tracker, no working spaced repetition anywhere in the set. |
| 4. Nearly every project treats the learner as a consumer. The very few that treat the learner as an author or contributor are the ones with a durable data moat. |
| 5. The projects that win on distribution are the ones that refused to build a destination: the Google Docs add-on, the MCP agent skill, the Discord bots, the sidebar extensions. They ride existing habits instead of asking for a new one. |
| 6. Screens are an unexamined assumption. Exactly two projects (Shulkhan, the TRMNL plugin) serve people who will not or should not learn from a phone, and both are effectively prototypes. That constituency is large and almost entirely unserved. |
| NaN |
| THE OPEN WHITE SPACE |
| Working spaced repetition over text references. A study record that spans decades and is worth switching costs. Adaptive Hebrew decoding that listens to the learner read. A hosted, write-capable agent layer over the corpus. Correct Hebrew nikud rendering in reflowable e-book formats. Cheap camera-over-paper overlay so the printed sefer stays the interface. A verifiable learning transcript institutions would accept. |
