# Baseline / Corpus Project: A-to-Z Roadmap

This is the 90-day execution plan to launch the independent research shop, establish empirical authority, and secure the first lab/foundation conversations.

## Division of Labor Principle
*   **Claude (Agent):** Writes code, parses data, scaffolds platforms, writes evaluation harnesses, generates synthetic datasets, and formats reports.
*   **Elie (Human):** Conducts high-level strategy, reviews and validates halachic ground truth, distributes content to networks, talks to users/buyers, and writes the authoritative "voice" pieces.

## Phase 2: The Empirical Authority (Weeks 3 - 5)
**Goal:** Launch the Orthodox AI Adoption Survey and gather the data no one else has.

*   [x] **Agent:** Draft survey methodology and branching logic.
*   [ ] **Agent:** Build the survey tool (or configure Typeform/Qualtrics schema) ensuring zero IP tracking.
*   [ ] **Elie:** Distribute the survey to 3 distinct networks: Institutional, Educator, and Layperson. Push for >500 responses.
*   [ ] **Agent:** Ingest the survey results, run statistical analysis (cross-tabbing concerns by segment), and generate charts.

*   [ ] **Elie:** Distribute the report to journalists, foundations, and institutional boards.

## Phase 3: The Lab Wedge (Weeks 6 - 8)
**Goal:** Build and run the Halachic Reasoning Eval (HRE), our technical product.

*   [x] **Agent:** Draft HRE technical specification and seed questions.
*   [x] **Agent:** Expand HRE to a 100-question `.jsonl` dataset (Temporal, Probabilistic, Hierarchical, Hallucination, Semantic).
*   [ ] **Elie:** Audit the 100 questions. Correct any halachic subtleties to ensure absolute ground-truth perfection. (This MUST be bulletproof).
*   [ ] **Agent:** Write the Python Evaluation Harness to run the `.jsonl` against OpenAI (gpt-4o) and Anthropic (claude-3.5-sonnet) APIs.
*   [ ] **Agent:** Execute the eval run and format the output matrix (Accuracy, Precision, Common Failure Modes).
*   [ ] **Elie:** Author the whitepaper: "Frontier Models Fail at 2,000-Year-Old Formal Logic." 
*   [ ] **Elie:** Send the whitepaper and the dataset directly to safety/alignment researchers at Anthropic and OpenAI.

*   [ ] **Elie:** Begin publishing a weekly Substack/newsletter analyzing one Jewish AI tool or trend per week (using the 110-tool backlog).
*   [ ] **Agent:** Build a pipeline to monitor new Jewish AI tools and automatically add them to a staging queue for the Registry.
*   [ ] **Elie:** Pitch pre-grant technical diligence services to Maimonides and other foundations based on the survey and registry.
*   [ ] **Elie:** Pitch custom religious-bias/reasoning evals to AI labs based on the HRE whitepaper.
